## Order
`T005–T009` → `T010–T012` → `T013–T015`. Дефекты из одного файла не править параллельно, пока нет базового скриншотного эталона.

## Safeguards
- Сохранить рабочую геометрию/палитру/анимации; нельзя переоформлять сигнальное предупреждение о риске потери данных просто ради единообразия.
- Старые CSS-правила `.feature-art` не удалять в пилотном этапе: отсутствие использования в текущем HTML не доказывает, что их можно удалять без последствий.
- План и список задач **написаны по доступным исходникам**; это не доказательство запуска CLI-команд `speckit-plan` или `speckit-tasks`.

## Verification Protocol
1. Зафиксировать базовую ревизию, вариант APK, плотность экрана, размер шрифта, тему, локаль, экран и состояние.
2. Снять скриншоты 4 разделов, модальных окон и предупреждения; проверить width 320/360/393/412 CSS px, системный масштаб 100% и увеличенный.
3. Для A01 сравнить computed `background-color` карточек аналитики с inline `!important`. Для A02–A03 проверить реальные clickable bounds и ошибочные касания.
4. Для A04 измерить фактический font-size, контраст и усечение. Для A05 воспроизвести безопасную ошибку хранения без повреждения данных.
5. Только после подтверждения — тест, минимальный CSS/markup diff, повторный проход и `npm run verify`, затем Android debug build и проверка сохранности записей.
6. В отчёте перечислить отдельно: фактически запущенные проверки, тесты на устройстве, не проверенное.

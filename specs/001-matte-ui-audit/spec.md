# Спецификация 001 — инвентаризация и план матового интерфейса

**Статус:** draft · **Ветвь:** `experiment/spec-kit-rashodypro-2026-10-31`

## Контекст
В «Расходы PRO» необходимо проверить весь интерфейс: отдельные кнопки, карточки, рамки, мелкий текст и состояния могут оставаться яркими либо глянцевыми. На этом этапе **только инвентаризация, спецификация, план и критерии проверки**. Реализация нового UI в пилот установки не входит.

## Пользовательские сценарии
1. Пользователь открывает каждый раздел и видит согласованную матовую 3D-систему без случайных ярких элементов.
2. Пользователь различает текст и активные/неактивные состояния, в том числе в модальных окнах, клавиатуре и формах.
3. После косметической правки все уже сохранённые записи и категории остаются доступны, операции с финансами работают без изменений.

## Требования
- **FR-001:** На основе реального `www/index.html`, `www/*.css` и связанных JS-обработчиков составить перечень всех экранов и состояний.
- **FR-002:** Для каждого дефекта перечислить элемент, исходный селектор/обработчик, желаемый вид, риск каскадных CSS-эффектов и способ проверки.
- **FR-003:** Сохранить существующие размеры, логику операций, навигацию, SQLite, экспорт/импорт и производительность без иных требований.
- **FR-004:** План должен опираться на `npm run verify` и существующие проверки проекта, а не на придуманные тесты.
- **FR-005:** Все изменения следующей реализации должны быть минимальными, разделёнными по связанным компонентам и сравниваться с текущим UI.

## Критерии приёмки пилота
- **AC-001:** Получены таблица дефектов/поверхностей и карта рисков с указанием реальных исходных файлов.
- **AC-002:** Есть план тестов и способ сравнения до/после на утверждённом референсе.
- **AC-003:** В рамках установки Spec Kit файлы `www/`, `native/`, `package.json` и текущие процессы Android-сборки не изменены.
- **AC-004:** Пользовательские данные и APK в рамках данного пилота не затронуты.

## Вне объёма
Переписывание проекта, внесение массовых CSS-изменений, миграции данных, новые функции, выпуск APK, заявления о FPS без измерений.

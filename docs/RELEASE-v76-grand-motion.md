# Расходы PRO — v7.6 Grand Motion (тест)

Отдельная тестовая Android-сборка (applicationId `ru.rashody.pro.preview76`).
Не заменяет основное приложение и не изменяет его SQLite-хранилище.

## Анимации

- Календарная полоса: волнообразное 3D-появление всех семи дней с задержкой и прорисовкой полос расходов (1200 мс + stagger).
- Три финансовые карточки: подъём, наклон, глубина, мягкое пружинное приземление (1390 мс).
- Круговая диаграмма дня: объёмное появление и поэтапная прорисовка SVG-сегментов (1460–1510 мс).
- Аналитика: анимация KPI, сегментов диаграммы, легенды и столбцов.
- Выбор даты: отдельная длинная анимация; изменение суммы и диаграммы вызывает обновление визуальных эффектов.
- Неанимированные состояния после завершения; отключение декоративных анимаций на реальном касании, прокрутке или `prefers-reduced-motion`.

## Безопасность

Финансовые формулы, хранилище SQLite и логика сохранения операций не изменены. Система 3D PNG из v7.5 сохранена.

## Контроль качества

`npm run verify`, `node --check`, Android SDK 36 + Gradle `assembleDebug` и проверка APK-ассетов.
Проверка плавности на физическом Android-устройстве **не проводилась**.

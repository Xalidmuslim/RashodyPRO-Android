# Расходы PRO v7.7 — SCULPTED MATTE MOTION (тест)

## Внедрено
- 3 новых матовых 3D PNG-ассета под календарём: кошелёк, чек и покупка. Генерируются перед Capacitor sync в `www/assets/icons/kpi/`.
- Компактные карточки с обработкой нажатия и 790-мс 3D-разворачиванием в панель статистики. Данные берутся из текущих операций, а не из примеров.
- Главная диаграмма увеличена; выделенный сектор при выборе меняет толщину и пространственное положение; остальные приглушаются.
- В центре выбранная категория и сумма; под диаграммой — операции этой категории. Выбор другого сектора не пересоздаёт весь экран.
- Согласованы анимации заголовка, календаря, статистики, диаграммы и строк операций. Быстрый press 135–160 мс, мягкий возврат 720–920 мс.
- Переход активной даты с измеренным смещением, 3D-подъём иконки при переходе нижней навигации.
- Открытие формы операции получает пространственный переход от FAB или выбранной строки; добавление/удаление подаёт анимационный сигнал списку.
- Android-кнопка «Назад» закрывает открытую 3D-панель.

## Ограничения
- Детали операции продолжают открываться в существующем редакторе; физическое раскрытие строки внутри списка пока не реализовано полностью.
- Удаление уже существующей операции отображается через плавную перестройку нового списка, но не через анимацию исчезновения удаляемой строки.
- Кнопки и все разделы, не перечисленные выше, используют прежние motion-компоненты и требуют отдельной визуальной проверки.
- Не проводились профилирование на физическом Android-устройстве, FPS и frame-time замеры; стабильные 120 FPS **не подтверждены**.
- Это отладочная изолированная установка `ru.rashody.pro.preview77` — отдельно от основного приложения. Финансовые данные основной установки не меняются.

## Автоматические проверки
`npm run verify` (включая `verify-sculpted-v77.mjs`), Android SDK 36, Gradle `assembleDebug`, PNG проверка внутри APK, `unzip -t`, проверка `versionName`, `git diff`.
Публиковать APK только после успешного завершения CI.
